# Papers-Go Documentation · 使用文档

Papers-Go 是一个可自行部署的论文发现、推荐与辅助阅读网站。本手册介绍安装部署、日常使用、管理配置和运行维护。

Papers-Go is a self-hosted application for discovering, recommending, and reading research papers. This manual covers installation, everyday use, administration, and maintenance.
