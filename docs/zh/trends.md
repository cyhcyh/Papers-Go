# 趋势和热点

[目录](index.md) · [English](../en/trends.md)

## 功能入口

首页“每日趋势”提供简版概述，点击“查看趋势分析”进入“趋势雷达”。需要登录并设置有效兴趣方向。

当前分析围绕**最新一期 arXiv 公告的新稿**，结合用户关注方向和相关研究背景展开。它不是把数据库所有论文数量重新叙述一遍，也不保证每个自然日都有新的 arXiv 公告。

![趋势和热点](../images/trends.jpg)

## 页面内容

| 模块 | 展示内容 |
| --- | --- |
| 当日热点 | 本期已确认主题中的热点；同一主题至少 3 篇新稿才展示 |
| 方向发展概述 | 按关注方向概述问题、方法、结果及其意义 |
| 每日概览 | 对本期研究焦点作整体简述 |
| 收藏作者的新动向 | 所关注作者近 7 天的论文动向 |

首页使用短版，趋势页展示较完整的内容。方向概述重在研究发展，不在正文下面堆放论文链接列表。

## 如何获得相关趋势

1. 在“设置 → 我的兴趣”添加长期兴趣、有效的近期关注或正式主题。
2. 保存并等待兴趣更新完成。
3. 打开趋势页，查看页面标注的 arXiv 公告日期。
4. 如果显示正在整理，等待后台“方向趋势简述”任务处理。

宽泛方向可以写成明确问题。例如，“组合数学”可进一步描述为“图着色中的列表约束与极值结构”。这有助于区分真正相关的方法和结果。

## 如何理解状态

- **主题统计尚未完整**：部分论文仍待分类或主题待批准，当前热点只基于已确认部分。
- **暂无热点**：不一定没有论文，可能尚未达到展示阈值。
- **等待最新一期 / 正在更新**：公告同步、主题确认或报告正在处理。
- **无匹配进展**：本期材料对该方向不足，不应把这解释为整个领域没有进展。

公告日期、论文公开日期、本站收录日期和报告生成时间是不同的时间口径，应按页面标注理解。

## 管理员调整生成内容

入口：后台 → 模型配置 → Prompts。方向趋势相关指令为 `trend_report`，表达整理相关指令为 `trend_rewrite`。调整时说明希望关注的科学问题、方法变化、结果证据和篇幅，保持输出结构要求。

对应模型在“功能分配 → 方向趋势简述”设置。任务中心的“方向趋势简述”负责公告准备及报告生成，与只计算主题数量的“趋势聚合”不同。
