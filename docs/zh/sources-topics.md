## 三个概念

| 名称 | 示例 | 作用 |
| --- | --- | --- |
| 学科 | Mathematics、Computer Science | 组织研究方向与来源 |
| 来源分类 | `math.CO`、`cs.LG`、ICML | 控制论文抓取和来源标签 |
| 研究主题 | Ramsey 理论、强化学习 | 表达论文最相关的研究方向 |

当前版本使用站点的**研究方向目录**，包含内置的候选方向，也允许管理员维护和批准新增方向。候选目录条目不等于已发布主题；新安装仍需配置抓取来源并通过添加或批准建立正式主题。旧版本中 MSC / ACM 的历史分类说明不能直接套用到当前目录。

## 分类与来源

入口：后台 → 分类与来源。列表支持搜索、分页、多选及批量管理。

### 添加 arXiv 分类

1. 打开新增 arXiv 分类入口。
2. 从分类目录选择需要的条目，可批量添加。
3. 设置自动抓取、游客默认及页面提供的排序等参数。
4. 保存后，到任务中心执行抓取。

新增来源不会自动抓取历史全部论文，也不会自动产生主题标签。正常增量任务按来源同步窗口分页获取，首次试运行另有数量上限。

### 添加会议

选择会议目录中的条目，或按页面填写会议代码和受支持的 feed 地址。示例：`https://papers.cool/venue/AAAI/feed`。保存前使用来源测试查看返回年份、论文数和标题。

会议同步关注来源提供的最新届次，不扫描所有历史年份。会议论文以会议作为来源分类，例如 ICML，而不是统一标成 `cs.AI`。论文也可能同时具有其他已登记来源关联。

### 修改与批量操作

可修改来源名称、抓取设置、游客默认等字段。批量选择后可统一修改自动抓取和游客默认，或进入批量删除。关闭自动抓取保留已有论文；关闭游客默认改变游客来源范围。

### 删除来源

先查看删除预览，核对会删除和保留的论文数量，再按要求输入确认内容。

- 仅属于被删来源、没有其他保留来源关联的论文一并删除。
- 仍属于其他保留来源的论文保留，移除被删来源关联并调整标签。
- 删除在后台执行，可查看进度；失败时按页面提供的重试操作处理。

> 来源删除可能同时移除论文及其关联缓存、标签和个人引用。它与停用主题完全不同，应先备份。

## 主题管理

![主题管理](../images/topic-management.jpg)

左侧按来源组织主题树，右侧展示分页列表，支持搜索、状态筛选和批量管理。手机端使用可展开的主题树抽屉。

### 添加或批准主题

普通用户从目录选择并提交提议。Agent 可以提议已有方向，也可以新拟方向；后台会标明来源。

批准提议时，切换到待审核列表，打开需要核对的记录，检查中文名、英文名、描述及所属主类，再点击“批准”。需要修改时先编辑保存，不合适时拒绝。

管理员直接添加的步骤：

1. 点击新增主题入口。
2. 填中文名称，例如“Ramsey 理论”。
3. 填英文名称，例如 `Ramsey Theory`。
4. 选择学科，例如 Mathematics。
5. 在“方向描述（英文）”填写问题与范围，例如 `Ramsey-type problems for graphs and hypergraphs.`。
6. 在“所属主类”勾选关联来源，例如 `math.CO`，然后保存。

每篇论文选择 **一个最相关主题**。批准时会关联等待该主题的论文；部分论文仍需后续分类。

### 编辑主题

修改主题显示名称或说明后，论文通过主题 ID 关联到当前主题信息，页面重新加载后显示新名称，不需要逐篇重新生成标签文本。

更改主题的科学含义与仅修改名称不同：如果原有论文不再符合含义，应安排重新分类。目录基础信息与具体主题的显示编辑也可能分别保存。

### 停用与彻底删除

| 操作 | 结果 |
| --- | --- |
| 停用 / 拒绝 | 移除相关论文标签和兴趣引用，论文保留；阻止同一已禁用方向反复提议 |
| 恢复 / 批准 | 重新启用，按当前状态关联待批准论文 |
| 在归档主题中彻底删除 | 清除主题及其禁用记录，之后 Agent 可再次提议；论文、喜欢和收藏保留 |

批量按钮会按所选状态筛选可操作对象，执行后检查成功与失败列表。
