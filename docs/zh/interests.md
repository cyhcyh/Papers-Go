# 兴趣与个人设置

[目录](index.md) · [English](../en/interests.md)

入口：“设置”。需要登录。当前有“基本设置”“我的兴趣”“通知管理”“我的技能”四个子标签页。

## 基本设置

用户名在个人页面只读，由管理员管理。外观可选择亮色、暗色或跟随系统。

修改密码时填写原密码、新密码和再次确认的新密码。新密码为 8～128 位，两次输入须一致。修改成功后退出登录，再使用新密码登录。

## 我的兴趣

兴趣画像使用表单，无需编辑 Markdown。

| 字段 | 作用 | 示例 |
| --- | --- | --- |
| 研究方向描述 | 帮助助手理解背景、经验及问题 | 正在研究稀疏图上的结构与着色问题 |
| 长期兴趣 | 持续影响推荐和趋势 | 极值图论、图着色 |
| 近期关注 | 阶段性优先方向，可设置结束日期 | 本月关注列表着色的新上界 |
| 关注程度 | 一般、持续、重点关注 | 重点关注 |
| 排除内容 | 表达不希望推荐的方向 | 与当前研究无关的应用场景 |
| 分类与主题 | 设置论文来源与正式主题范围 | `math.CO` 及其中已批准主题 |

研究方向描述主要供助手理解背景。用于推荐和趋势的方向，还应填入长期兴趣、近期关注或选择主题。

### 保存兴趣

1. 填写研究背景。
2. 添加长期兴趣、近期关注及必要的排除项。
3. 勾选分类和主题。勾选主类会同时选择其下当前展示的主题，可再调整具体主题。
4. 点击保存。
5. 页面可能显示“推荐正在后台更新”，等待状态完成后回到首页。

保存表单和生成兴趣向量分为两个阶段。模型服务不可用时，后台更新可能等待或失败；请查看状态，而不是反复提交同一内容。

兴趣画像保留当前版本与最多 **3 个历史版本**。版本号持续递增，历史不会无限增长。行为反馈和每周画像反思也会参与兴趣调整。

## 主题提议

在“我的兴趣”中的主题提议区域，搜索研究方向目录，选择条目、所属来源并说明理由，然后提交。

普通用户的提议由管理员审核，批准后才成为正式主题。当前代码使用站点研究方向目录，目录与已批准主题是两个概念，详情见[分类、来源与主题](sources-topics.md)。

## 我的监视清单

可添加关键词、基准、作者或主题监视项。输入要明确，避免只填写过于宽泛的词。

监视清单依赖“预警评估”等后台任务运行后产生通知，并不是实时监听所有外部网站。取消监视后不再按该项生成新预警。

## 通知管理

页面按通知方式展示设置卡片。可控制站内通知及 Telegram，并填写自己的 Telegram Chat ID。Telegram 发送还需要管理员配置机器人凭据；仅填写 Chat ID 不能完成服务端接入。

在“通知中心”查看通知、处理已读状态。是否有新通知同时取决于个人开关、匹配到的论文及后台任务。

## 我的技能

在“我的技能”管理个人技能，或提交共享提议。技能的使用和审核见[智能助手与 Skills](assistant.md)。
