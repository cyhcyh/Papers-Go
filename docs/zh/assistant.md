# 智能助手与 Skills

[目录](index.md) · [English](../en/assistant.md)

## 开始对话

入口：“智能助手”，或论文卡片上的“问 AI”。需要登录，并已配置智能助手模型。

1. 点击“新对话”，输入研究问题。
2. 按 Enter 发送，Shift + Enter 换行。
3. 从论文进入时，说明希望解释的方法、公式或结果。
4. 助手逐步显示正文；模型内部思考过程不作为回复展示。

回复支持 Markdown、列表、表格和数学公式。回答中的论文引用可用于返回相关论文。

## 会话管理

电脑端从会话列表切换历史会话，手机端通过可展开的会话抽屉访问。可以选择多个会话进行批量管理和删除。

删除会话会删除该会话的历史，不能通过刷新恢复。共享论文及精读缓存不随个人会话删除。

## 助手能做什么

| 工具能力 | 作用 |
| --- | --- |
| 检索论文 | 搜索本站已收录论文，返回相关信息 |
| 请求精读 | 将指定论文加入精读队列或读取已有结果 |
| 查看兴趣 | 使用当前用户的兴趣画像理解背景 |
| 提议更新兴趣 | 展示变更提议，等待用户确认后保存 |
| 提议添加监视项 | 展示监视项提议，等待用户确认 |
| 使用技能 | 查找、读取、激活当前用户可访问的技能 |
| 制作个人技能 | 创建或编辑用户自己的技能，再按需提交共享提议 |

工具的用户身份来自登录会话，不由模型自行指定。助手没有任意后台管理、修改其他用户数据或执行系统命令的通用工具。共享论文检索与私有用户数据的访问范围不同。

看到兴趣或监视项变更卡片时，先检查内容，再确认或拒绝。普通解释性回答不会自动把建议写入兴趣设置。

## 上下文与记忆

会话消息保存在个人会话中。助手结合当前兴趣画像、论文上下文、工具返回结果及按需加载的技能回答。较长对话可使用独立的“上下文压缩”模型，将较早内容整理为摘要。

长期研究偏好保存在兴趣画像中，论文与兴趣向量用于检索和推荐。模型本身不会因为一次对话永久训练出记忆；需要长期生效的方向，应保存到兴趣设置。

## 我的技能

入口：“设置 → 我的技能”。技能由说明文件和可选资源组成，用于约定助手的研究流程，例如“比较两篇论文的假设、方法和结果”。

1. 创建个人技能，填写名称、简介和指令，按需加入资源。
2. 保存并启用。
3. 在对话中说明希望使用哪项技能，助手按需读取和激活。
4. 如需与其他用户共享，提交共享提议，由管理员批准。

个人技能只在允许的个人范围内管理；共享技能和系统技能由管理员维护。技能不会凭空增加后台权限，指令中的工具调用仍受应用允许的工具与身份检查限制。

## 管理员维护技能

后台 → 模型配置 → Skills 可管理系统技能、共享提议和版本。质量评估使用的系统技能位于默认源码 `backend/app/skills/paper-quality/SKILL.md`，后台编辑保存为运行配置。

技能变更用于新调用。系统会保留有限的历史版本，不应把技能版本记录当作完整数据备份。
