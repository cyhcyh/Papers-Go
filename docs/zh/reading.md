# 论文精读

[目录](index.md) · [English](../en/reading.md)

## 功能说明

论文卡片上的两项速读用于快速判断相关性，精读卡则根据论文全文回答六个问题。两者由不同任务生成。

打开论文“展开”，点击“生成精读卡”；生成需要登录，且管理员已分配精读模型。完成的共享结果可供之后查看同一论文的用户复用。

![六问精读卡](../images/reading-card.jpg)

## 六个问题

| 项目 | 阅读重点 |
| --- | --- |
| 研究问题 | 问题、背景和难点 |
| 已有研究与本文定位 | 已有方法以及本文的区别 |
| 核心方法 | 方法步骤、关键定义、公式与假设 |
| 关键结果与证据 | 实验或理论结果，以及支撑材料 |
| 后续研究方向 | 作者指出的方向和可进一步探索的问题 |
| 核心总结 | 简明概括论文价值 |

“论文精读”为 L2，“深度解析”为 L3。L3 使用独立的模型功能分配，主要用于更深入的方法和证据分析，不表示结论自动更可靠。

## 生成过程

请求先进入数据库队列，后台 worker 取得额度后获取和解析全文、调用模型、整理并回验结果。普通论文直接使用全文；超过可用上下文时会分段整理，再生成完整分析。

页面会逐步显示已生成的答案。模型思考内容会隐藏，思考阶段显示状态和已用时间，不显示估算百分比。

| 页面状态 | 说明 | 您可以做什么 |
| --- | --- | --- |
| 排队中，前面还有 N 位 | 同类资源队列中尚有 N 个等待任务 | 关闭页面，稍后回来 |
| 材料准备 | 获取、解析或整理全文 | 等待材料阶段完成 |
| 思考 / 生成中 | 模型正在处理，逐步返回可展示内容 | 查看用时与已完成的问题 |
| 回验 / 完成 | 核对证据并保存结果 | 阅读答案和引用 |
| 失败 | 网络、全文、模型或解析未成功 | 查看错误，按页面提供的重试操作处理 |

排队人数不是预计分钟数，也不包含所有正在生成的任务。不同论文的篇幅与模型速度不同，无法据此精确估计结束时间。

## 异步与共享缓存

- 关闭弹窗、切换页面或断开浏览器连接不会取消已接受的排队与生成请求。
- 同一论文的重复请求会复用现有任务，完成后复用缓存。
- 已完成 L3 可以满足较浅的查看需求；已有 L2 后请求 L3 可能需要升级生成。
- worker 重启后保留尚未开始的等待任务；已经在调用模型的任务会标记为中断，需要重试。
- 重新生成共享缓存由管理员操作，普通用户不能随意覆盖他人已生成的结果。

“Top 5 预读”可提前准备热门推荐的精读结果。它与用户请求共享精读资源额度。

## 数学、表格与证据

精读答案支持 Markdown 列表、表格和 LaTeX 数学公式。展开“关键结果与原文证据”可查看引用及回验标记。

“引文已在全文回验”表示找到相应原文片段，不表示模型已经证明该论断。未通过回验时应自行对照原文。若全文来源标为 arXiv 预印本，也应注意它与会议最终版本可能存在差异。

## 管理员并发设置

入口：后台 → 模型配置 → 功能分配 → 论文精读 / 深度解析并发限制。默认云端 / Codex 2 篇，本地 1 篇，可按服务额度和硬件调整。精读、深度解析和预读共享限制。
